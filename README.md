## Описание проекта

Страница «О себе» дополнена скриптом `script.js`, который обрабатывает результаты измерений эксперимента: находит среднее значение, фильтрует значения выше среднего, считает аномально низкие значения и оценивает разброс данных.

## Данные

Массив результатов измерений (любые единицы): `[45, 52, 3, 78, 61, 49, 5]`

## Реализованная логика

**Ввод/вывод**
- `prompt` - запрос имени пользователя (если имя не введено, используется «Исследователь»)
- `alert` - приветствие пользователя
- `alert` - «Среднее значение – X, Y измерений – выше среднего»
- `console.log` - исходные данные, количество аномально низких значений, сообщение о вариативности

**Функции**
- `getSum(arr)` - сумма элементов массива
- `getMax(arr)` - максимум в массиве
- `getMin(arr)` - минимум в массиве (для расчёта разброса)
- `filterAbove(arr, threshold)` - фильтрация: значения строго больше порога

**Условные конструкции и циклы**
- Цикл `for` для подсчёта аномально низких значений (≤ 10% от максимума)
- Условие `if`: если разброс (max − min) > 50, в консоль выводится «Наблюдается высокая вариативность данных»

## Результат для текущих данных

- Среднее значение: 41.86
- Выше среднего: 5 измерений
- Аномально низких значений (≤ 7.8): 2
- Разброс: 75, выводится сообщение о высокой вариативности
